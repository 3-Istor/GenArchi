# Application commune

Emplacement réservé à l’application web destinée aux deux plateformes. Aucun code, framework, manifeste de dépendances ou contrat d’API n’est encore défini.

Avant implémentation, confirmer le parcours MVP, les données persistantes et les technologies communes : [Q-006, Q-007 et Q-009](../docs/cadrage.md). Consigner les choix dans les [ADR](../docs/adr/README.md).

Lors de l’ajout du code, documenter ici les prérequis, la configuration sans secrets, les commandes réellement disponibles et les tests. Définir avec les deux chantiers infrastructure les besoins d’exécution et de vérification du service. Aucun choix d’endpoint ou de protocole n’est préétabli.
