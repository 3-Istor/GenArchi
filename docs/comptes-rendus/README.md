# Comptes rendus d’équipe

Copier le [modèle](modele.md) vers `AAAA-MM-JJ-sujet.md` après chaque réunion. Pour un coaching, utiliser les [modèles dédiés](../coaching/README.md).

Documenter les participants réels, les décisions explicites et les actions avec responsable et échéance. Laisser « à confirmer » lorsque l’information manque. Relier les décisions techniques aux [ADR](../adr/README.md) et les questions Q-xxx au [cadrage](../cadrage.md), puis mettre à jour ces registres avec un lien de retour vers le CR.

Aucun compte rendu de réunion tenue n’est disponible au démarrage. Le kickoff fourni est conservé comme support de proposition, sans inventer de participants, de validation ou d’actions réalisées.
