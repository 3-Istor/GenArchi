# Coaching

Conserver une préparation et une restitution distinctes pour chaque séance :

- `AAAA-MM-JJ-preparation.md`, à partir du [modèle de préparation](modele-preparation.md).
- `AAAA-MM-JJ-restitution.md`, à partir du [modèle de restitution](modele-restitution.md), après la séance.

La [préparation du 3 novembre 2026](2026-11-03-preparation.md) reprend les pistes du kickoff. La tenue et les conclusions de la séance restent à confirmer ; aucune restitution factice n’est créée.

Le [support du premier coaching](2026-11-03-coaching-1.pptx), comprend six diapositives : rappel rapide du projet, comparaison P2/P3 par deux schémas illustratifs inspirés du kickoff, deux pages libres avec uniquement les titres pour les schémas de l’équipe (3 et 5), l’architecture P2 proposée par le chantier P2 (4, [CR](../comptes-rendus/2026-11-03-seance-p2.md)), puis une liste de questions sur une seule diapositive. Les notes du présentateur précisent les questions et citent les supports sources. Les architectures restent des propositions à discuter.

Référencer les questions du [cadrage](../cadrage.md) plutôt que créer un registre concurrent. Après la séance, y reporter les réponses sourcées et les dates officiellement confirmées. Relier les choix techniques aux [ADR](../adr/README.md) ; une réponse du professeur sur une consigne et une décision d’équipe doivent rester distinguées.
